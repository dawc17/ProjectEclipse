# Dojo Selector

Enable, Apply & Restart, and find Dojo Selector using the map-page dots. Press
FIGHT to open the game-themed chooser. Select BATTLEFIELD DOJO, then enter Dojo
from the normal game menu. No fight starts and no reward is granted by the chooser.

The backdrop should use the animated battlefield. Exit/reenter and restart to
check persistence. Disable this mod and restart: the normal dojo should return.
Reenable and restart: the retained preference should restore the battlefield.
RESTORE DEFAULT explicitly clears this mod's preference. It is disabled when
another mod owns the saved selection. BACK and Escape leave the selection intact.

This example uses existing art and the standard UI theme. Full-game appearance,
profile persistence, controller focus and scene transitions still need acceptance.

# Quest suppression

Enable this example and Apply & Restart. Enter the map: only the replacement
introduction should appear. The old registered quest stays present but cannot run.
Remove the suppress call and restart to see both introductions. Disabling the
example removes its presentations; no core quest, item, reward or price is changed.

For dependency/core targets, use a declared dependency and the source-aware
identity documented in the public quests reference. Full native dialog acceptance
is a manual check; Lua registration and conflict rollback have automated fixtures.

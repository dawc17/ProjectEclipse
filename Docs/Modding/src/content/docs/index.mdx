## How to read the reference

Every public function and combat callback has its own section. **Signature** shows how to call it, **Requires** lists permissions and dependencies, **When** explains the valid time to call it, and **Returns** explains the result. Field tables mark required inputs, defaults, and limits. Reference snippets may use handles defined earlier on the page; the beginner tutorial supplies complete files.

This wiki documents the implemented Eclipse API. It covers supported behavior and clearly labels compatibility forms and current limits. Your mod's manifest declares which API versions it accepts.

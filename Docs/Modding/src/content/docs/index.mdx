## Find a system

- **Content API** covers equipment, shops, sprites, battles, quests, perks,
  localization, and asset replacement.
- **Behavior and progression** covers saved state, combat callbacks, events,
  modes, offline raids, and achievements.
- **Compatibility and status** explains legacy forms, current limitations,
  and the scope of recorded verification.

## What this wiki documents

This is the public **Eclipse** modding API. Definitive Edition is a downstream
content target. Planned DE parity does not imply that every recovered XML field
or gameplay event is available to Lua.

Reference pages are built from the repository's maintained API documentation.
Each has an **Edit page** link to its original source. Historical version labels
describe when a feature arrived; read the current limitations before using it.

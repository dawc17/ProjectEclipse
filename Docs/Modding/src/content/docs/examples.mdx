Use the smallest example that covers your feature. The complete source lives in
the repository's `Mods/` folder, including manifests, scripts, localization, and
assets. Folder names containing a phase identify development fixtures, not a
required learning order.

| Example | What to learn |
| --- | --- |
| [example.weapon](https://github.com/dawc17/ProjectEclipse/tree/main/Mods/example.weapon) | One weapon, a loose sprite, a core model, and a shop listing. |
| [example.loadout](https://github.com/dawc17/ProjectEclipse/tree/main/Mods/example.loadout) | Armor, helm, ranged, and magic using core assets. |
| [example.enchantment](https://github.com/dawc17/ProjectEclipse/tree/main/Mods/example.enchantment) | Reusable typed behavior shared by a perk and an enchantment; legacy template compatibility. |

Follow <a href={pageUrl('guides/first-weapon')}>Your first weapon</a> for a guided
walkthrough of the smallest example.

## Integrated showcases

- <a href={pageUrl('showcases/content')}>Content showcase</a>: battles, quests,
  equipment, progression, locations, moves, and ordinary tactics.
- <a href={pageUrl('showcases/combat-and-modes')}>Combat and modes showcase</a>:

- <a href={pageUrl('showcases/achievements-and-assets')}>Achievements and assets showcase</a>:

Each walkthrough includes its recorded verification and known limits. Follow its
restart instructions when testing changes; an already running session does not
automatically become a fresh registration session.

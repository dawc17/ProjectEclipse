You will make **Training Blade**, a katana that appears in the weapon shop at level 1 for one coin. You need an Eclipse build with Mod API 0.7, a text editor, and the sample image linked below. You do not need Unity or a Lua installation; Eclipse runs the script for you.

If code is new to you, keep <a href={pageUrl('guides/lua-basics')}>Lua basics</a> open alongside this page. Copy each complete file first, get the mod working, then experiment.

## 1. Create the folder

Open the game's `Mods` directory and make a folder called `tutorial.blade`. In a standalone desktop installation, `Mods` is beside the game executable; when working from the project, use its root `Mods` folder. A launcher-managed installation may use a shared Mods directory outside its version folders; use that installation's configured directory. Create these subfolders and files:

```text
Mods/
  tutorial.blade/
    mod.toml
    scripts/
      main.lua
    localizations/
      eng.toml
    assets/
      sprites/
        weapon.asset
      textures/
        weapon.png
```

Enable file extensions in your file manager so you do not accidentally create `main.lua.txt` or `mod.toml.txt`. Save text files as UTF-8. `mod.toml` must be directly inside the mod folder, without an extra enclosing folder.

<Code code={script} lang="lua" title="scripts/main.lua" />

Here is what the script does:

1. `require("sf2")` loads the API into a variable called `sf2`.
2. `register_weapon` defines the item and returns a *handle*, stored in `weapon`.
3. `localization.key` finds its translated name. `assets.sprite` finds your descriptor; omit `.asset` in this reference.
4. `assets.model` reuses the core katana model. Keep `subtype = "Katana"` with this model.
5. `shop.addItem` makes the weapon purchasable. Registration alone does not put an item in the shop or in your inventory.
6. `log.info` writes a message so you can tell that the script reached the end.

The local item ID becomes `tutorial.blade:items/weapon/training_blade`. The variable `weapon` holds a handle, not this string; passing it to the shop preserves the item's type and identity.

## 6. Enable and test it

1. Start Eclipse and open **Mods** on the title screen.
2. Enable **Training Blade**, inspect **Details** if it reports a problem, and choose **Apply & Restart**.
3. Enter Campaign, open the weapon shop, and find **Training Blade**. Use a profile that has reached the shop.
4. Buy it for one coin, equip it, and enter a fight. It should use the borrowed katana model.

If something fails, start with <a href={pageUrl('guides/troubleshooting')}>troubleshooting</a>. A missing mod usually means the folder or manifest is wrong. A listed mod with an error usually means a dependency, script, localization, or asset reference needs fixing.

## 7. Make one change

Exit the game, change the displayed name in `eng.toml`, save, and launch again. You should see the new name in the shop. Next, try changing the price from `1` to `5`. Saving a script does not update the running game.

For a separately distributed mod, change the folder name, manifest `id`, `name`, and `authors` before publishing. Use a unique ID, such as `yourname.training`. Keep that ID and the item's local ID stable after players start using it.
